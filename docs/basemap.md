# 底图

底图只作“地形参照”：淡纸色、山林、水系、主要道路与省县界；**不含任何文字**。
历史地名由我们按史料自己叠加（避免今名与史实混淆，也无需字体文件）。

## 自托管切片

- 文件：`public/tiles/basemap.pmtiles`（约 31 MB，Protomaps 矢量瓦片，z0–z10）。**多个区域合并在同一个文件里**，每个战役占一个区域：

  | 区域     | bbox（西,南,东,北）     | 用于       |
  | -------- | ----------------------- | ---------- |
  | 川黔滇   | `101.5,24.5,108.5,29.5` | 四渡赤水   |
  | 豫北冀南 | `112.6,32.7,118.3,37.0` | 官渡之战   |
  | 诺曼底   | `-2.7,48.95,0.4,51.0`   | 诺曼底登陆 |

- 随站点一起部署，浏览器通过 HTTP Range 请求按需读取，**不依赖任何境外地图服务**。
  静态托管必须支持 Range 请求：GitHub Pages、腾讯云 COS/CDN、Nginx 默认都支持。
- 超过 z10 的缩放由 MapLibre 过采样。

## 重新生成或扩大范围

需要 Python 3 和 `pip install pmtiles requests`：

```bash
python scripts/basemap/extract.py 20260928 public/tiles/basemap.pmtiles \
    --bbox=101.5,24.5,108.5,29.5 \
    --bbox=112.6,32.7,118.3,37.0 \
    --bbox=-2.7,48.95,0.4,51.0 \
    --maxzoom 10
```

`--bbox` 一律写成带等号的 `--bbox=西,南,东,北`：西经、南纬的负数如果写成 `--bbox -2.7,…`，会被命令行当成选项而报错。

**每新增一个战役区域，就在命令里追加一个 `--bbox`，并把它加进上面的表格**；所有区域要一起重新生成，且使用同一个构建日期，这样各战役的底图风格一致。
第一个参数是 Protomaps 每日构建的日期（<https://maps.protomaps.com/builds/> 可查看可用日期）。
脚本只用 Range 请求读取范围内的瓦片，不会下载上百 GB 的完整文件。
z11 会使文件增大数倍，非必要不要提高。
